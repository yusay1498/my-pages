# 記事の書き方ガイド

このブログに記事を追加する方法を紹介します。

## 記事の構成

記事は `posts/` ディレクトリの中に、テーマごとのフォルダとして管理されています。

```
posts/
└── テーマ名/
    ├── meta.json          # テーマのメタ情報
    ├── 1.first-article.md  # 1つ目の記事
    ├── 2.second-article.md # 2つ目の記事
    └── 3.third-article.md  # 3つ目の記事
```

### meta.json

各テーマには `meta.json` が必要です。テーマのタイトルや説明、公開状態などを定義します。

```json
{
  "title": "テーマのタイトル",
  "description": "テーマの説明文",
  "tags": ["タグ1", "タグ2"],
  "createdAt": "2026-05-16",
  "updatedAt": "2026-05-16",
  "status": "published"
}
```

- `status` を `"draft"` にすると非公開、`"published"` にすると公開されます

### 記事ファイルの命名規則

```
{番号}.{スラッグ}.md
```

- **番号**: 表示順を決める数字（1から始まる）
- **スラッグ**: 記事の内容がわかる英語の名前（ハイフン区切り）

例: `1.introduction.md`, `2.setup-guide.md`, `3.advanced-tips.md`

## スマホから記事を書く

このブログの大きな特徴は、**スマホからでも記事を追加・編集できる** ことです。

### 手順

1. **GitHub** のモバイルアプリまたはブラウザで、リポジトリの `posts/` フォルダを開く
2. 記事を追加したいテーマのフォルダに移動する
3. 新しい `.md` ファイルを作成し、内容を書く
4. コミットすると **自動でビルド・デプロイ** が実行される

### 新しいテーマを追加する場合

1. `posts/` フォルダ内に新しいフォルダを作成する
2. `meta.json` を作成する（最初は `"status": "draft"` にしておくと安心）
3. 記事ファイルを追加する
4. 準備ができたら `meta.json` の `status` を `"published"` に変更する

## 使える Markdown 記法

| 記法 | 説明 |
|---|---|
| `# 見出し` | 見出し（h1〜h6） |
| `**太字**` | 太字 |
| `- リスト` | 箇条書きリスト |
| `1. リスト` | 番号付きリスト |
| `` `コード` `` | インラインコード |
| ` ``` ` | コードブロック |
| `[テキスト](URL)` | リンク |
| `![alt](URL)` | 画像 |

## まとめ

- 記事は Markdown で書くだけ
- スマホからでも GitHub 経由で追加・編集可能
- コミットすれば自動デプロイ
